Architectural Context

The Critical Failures of Naive RAG

Failure Modes in Traditional RAG

  • ✕ Cross-Page Chunk Bleed: Contiguous text splitters span across page boundaries, resulting in hallucinated page numbers and compliance audit failures.
  • ✕ Lost Section Semantics: Plain text dumps strip away document headers and parent sections, leaving the LLM unable to identify context scope.
  • ✕ Forced Hallucinations on Irrelevant Queries: Without an explicit quality cutoff, LLMs fabricate answers from low-similarity retrieved noise.
  • ✕ Single-Provider Bottleneck: Direct reliance on one model provider creates vulnerability to rate limits (HTTP 429) and outages.
Impact: Enterprise compliance risks, degraded user trust, and unacceptable production downtime.

Our Enterprise Solution Architecture

  • ✓ Stateful Document Boundary Ingestion: Flushes buffers at page changes to enforce strict 1-to-1 page citations.
  • ✓ Dynamic Section Inheritance: Stateful header detection tags every chunk with its active logical section.
  • ✓ Deterministic Routing Gate: Max cosine score ≥ 0.72 quality threshold rejects noise instantly without LLM cost.
  • ✓ Multi-Provider Failover: Seamless `.with_fallbacks()` from Groq Llama 3.3 to Google Gemini 2.5 Flash.
Outcome: 100% audit-verifiable provenance, zero unnecessary generation cost, and resilient 24/7 uptime.

Phase 2: Ingestion Pipeline

Stateful Ingestion & Page-Boundary Flushes

ingestion.py
1

Hi-Res PDF Partitioning

Utilizes unstructured.partition_pdf(strategy="hi_res"). Employs computer vision models to distinguish visual layout classes (Title, Header, NarrativeText, Table, Footer), outperforming naive text dumps.

category in ["Title", "Header", "Headline"]
2

Stateful Section Pointer

Maintains an active state pointer current_section during element iteration. When a header is parsed, the previous buffer is flushed and the new section title is applied to all subsequent paragraphs.

chunk.metadata["section"] = current_section
3

Hard Page-Boundary Isolation

Whenever page_number changes, the text buffer is immediately flushed. Chunks are strictly forbidden from spanning multiple pages, guaranteeing deterministic 1-to-1 page citations.

chunk.metadata["page"] = page_num
TextSplitter Parameters: chunk_size = 500 chunk_overlap = 50

Structured Schema Enforcement: `CitedAnswer`

Pydantic v2

The `CitedAnswer` Contract

Enforces verifiable citations by constraining model output to strict JSON schema fields. Free-form hallucinated text is rejected at the validator layer.

class CitedAnswer(BaseModel):

is_answerable: bool

answer: str

source_pages: List[int]

source_sections: List[str]

✓ Auto-Sanitizing Validators: De-duplicates and sorts page numbers.
✓ Deterministic Rejection: Clears citation lists if is_answerable=False.

XML Context Wrapping & Grounding

Metadata tags are prepended into each chunk before wrapping inside XML tags in the system prompt.

<document_context>

[Page: 4 | Section: Executive Summary]

The Q3 revenue reached $42.5M, representing a 15% increase...

---

[Page: 7 | Section: Operating Expenses]

R&D expenditure was $8.2M...

</document_context>

Prompt Instruction: "Never introduce outside facts. Extract exact page numbers from [Page: X] and sections from [Section: Y]."

Phase 5: Production Deployment

Containerization (`Dockerfile`) & Runbook

Docker

Container Architecture Highlights

  • 1. Base Image: python:3.11-slim for minimal attack surface and lightweight layer size (~200MB base).
  • 2. Local OCR Dependencies: Installs tesseract-ocr and poppler-utils via `apt-get` for image and layout parsing.
  • 3. Layer Caching: Copies `requirements.txt` independently to avoid invalidating pip dependency layers on code updates.
  • 4. Isolated Runtime: Offline ingestion (ingestion.py) is intentionally excluded from container startup.
CMD ["chainlit", "run", "app.py", "--port", "8000", "--host", "0.0.0.0"]
